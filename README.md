# 스프린트 미션 1

## Product, ElectornicProduct, Article 클래스

각 클래스는 아래와 같은 프로퍼티와 메소드를 가집니다

- Product
  1. name : string
  2. description : string
  3. price : number
  4. tag : array
  5. images : array
  6. favoritcount : number
  7. favorite() : method
     
- ElectornicProduct
  1. name : string
  2. description : string
  3. price : number
  4. tag : array
  5. images : array
  6. favoritcount : number
  7. favorite() : method
  8. manufacturer : string
 
- Article
  1. title : string
  2. content : string
  3. writer : string
  4. likeCount : number
  5. createdAt : Date 객체
  6. like() : method
 
  ## ProductService.js와 ArticleService.js

  panda market에서 제공하는 api를 활용한 메소드 모음입니다.
